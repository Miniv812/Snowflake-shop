# Інтернет-магазин теплого одягу «Сніжинка»


## Опис проєкту
Вебзастосунок для онлайн-вітрини та продажу теплого одягу, взуття і зимового спорядження. Система підтримує багатопараметричну фільтрацію каталогу (за категорією, температурним режимом, матеріалом, кольором, розміром та ціною), роботу кошика з контролем залишків на складі, оформлення замовлень, перегляд історії покупок та панель адміністратора.


## Стек технологій
* Backend: Python 3, FastAPI, Pydantic
* Database: PostgreSQL, SQLAlchemy ORM, psycopg2
* Security: PBKDF2-HMAC-SHA256, HMAC-SHA256 Bearer-токени
* Frontend: HTML5, CSS3, JavaScript (ES6+), Web Storage API
* Infrastructure and VCS: Docker, Git, GitHub


## Структура коду
* `/src/models` — ORM-моделі таблиць бази даних PostgreSQL (`models.py`)
* `/src/schemas` — схеми валідації вхідних та вихідних даних Pydantic (`schemas.py`)
* `/src/services` — сервісний шар бізнес-логіки за принципами SOLID (`auth_service.py`, `catalog_service.py`, `order_service.py`, `exceptions.py`)
* `/src/api` — HTTP-контролери REST API (`auth.py`, `catalog.py`, `orders.py`)
* `/src/security.py` — хешування паролів, генерація та перевірка токенів доступу, розмежування ролей
* `/src/database.py` — налаштування підключення до PostgreSQL та керування сесіями БД
* `/src/main.py` — ініціалізація застосунку FastAPI, глобальна обробка винятків та початкове наповнення БД
* `/static` — клієнтська частина застосунку (`index.html`, `style.css`, `app.js`)


## Структура бази даних
* `users` — облікові записи покупців та адміністраторів
* `categories` — категорії товарів зимового одягу
* `products` — асортимент товарів, характеристики та залишки на складі
* `orders` — оформлені замовлення клієнтів та їхні статуси
* `order_items` — товарні позиції у складі кожного замовлення (розмір, колір, ціна)


## Основні ендпоїнти API
* `POST /api/v1/auth/register` — реєстрація нового покупця
* `POST /api/v1/auth/login` — авторизація користувача та отримання токена
* `GET /api/v1/catalog/categories` — отримання списку категорій
* `GET /api/v1/catalog/products` — отримання каталогу товарів із фільтрацією
* `POST /api/v1/catalog/products` — створення нового товару (Admin)
* `PUT /api/v1/catalog/products/{product_id}` — редагування товару (Admin)
* `DELETE /api/v1/catalog/products/{product_id}` — видалення товару (Admin)
* `POST /api/v1/orders` — оформлення замовлення (Customer)
* `GET /api/v1/orders/my` — отримання історії замовлень поточного покупця (Customer)
* `GET /api/v1/orders` — отримання списку всіх замовлень клієнтів (Admin)
* `PATCH /api/v1/orders/{order_id}/status` — зміна статусу замовлення (Admin)


## Основний функціонал
* Каталог товарів: відображення карток із характеристиками, фотографіями та актуальною кількістю на складі.
* Фільтрація та пошук: відбір за категорією, назвою, температурним діапазоном (від -5°C до -40°C), матеріалом, кольором, розміром та ціною.
* Кошик покупця: вибір кольору та розміру, перевірка доступних залишків перед додаванням, збереження стану кошика у localStorage для кожного користувача.
* Замовлення та історія: валідація номера телефону, автоматичне списання товарів зі складу під час оформлення та перегляд статусів власних замовлень.
* Панель адміністратора: додавання, редагування та видалення товарів (із захистом від видалення товарів, що є в замовленнях), зміна статусів замовлень клієнтів із поверненням залишків при скасуванні.

## Інструкція із запуску
1. Клонувати репозиторій: `git clone https://github.com/Miniv812/Snowflake-shop.git`
2. Перейти в директорію проєкту: `cd Snowflake-shop`
3. Запустити базу даних PostgreSQL у Docker: `docker run --name snizhinka-postgres -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=snizhinka_db -p 5432:5432 -d postgres:15`
4. Створити та активувати віртуальне середовище Python: `python -m venv venv` та `.\venv\Scripts\Activate.ps1` (для Windows) або `source venv/bin/activate` (для Linux/macOS)
5. Встановити залежності: `pip install -r requirements.txt`
6. Запустити сервер: `uvicorn src.main:app --reload`
7. Відкрити застосунок у браузері за адресою `http://127.0.0.1:8000` (документація API доступна за адресою `http://127.0.0.1:8000/docs`)
8. Облікові дані адміністратора за замовчуванням: email `admin@admin.ua`, пароль `admin`
